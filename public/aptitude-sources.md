# 인적성 연습의 유형 참고와 검증

수정일: 2026-10-13

문항은 기업 시험 문제를 전재하지 않은 독립 제작 문제 30개다. 숫자만 바꾼 150개 묶음은 교체했다. 표·그래프, 지문, 조건, 선지, 해설을 개별 작성했다. 실제 특정 기업 시험과 난이도가 동등하다는 검증이나 합격 예측은 제공하지 않는다.

## 공개 자료로 확인한 범위

- [삼성전자 채용 안내](https://www.samsung.com/sec/about-us/careers/hiring-process-information/kr/): GSAT의 수리력·추리력 영역.
- [SK하이닉스 2026 하반기 공식 공고](https://www.skcareers.com/Recruit/Detail/R261762): 인지역량의 언어·수리·추리력.
- [SK Careers Journal 공개 유형 소개·예시](https://www.skcareersjournal.com/m/379): 응용 계산, 도표·그래프 자료해석, 장문독해, 문단 배열, 빈칸, 추론의 유형 참고. 2015년 자료의 시간·문항 수·역사 영역을 현재 시험 규칙으로 사용하지 않았다.

## 구성

언어 10, 수리·자료해석 10, 조건 추리·명제 10문항. 각 영역은 실전 5개, 고난도 5개다. 실전은 기본 공식에 조건을 추가하거나 정보의 범위를 구분하는 문제, 고난도는 역산·구간 분할·조건부 확률·복수 배치·존재 명제·논증 평가 등을 포함한다. 난이도는 편집상 분류이며 실제 수험생 정답률로 보정한 척도는 아니다.

## 연습 규칙

5지선다, 문제당 선택 1회, 제한시간 60초. 자동 힌트 없이 필요할 때 풀이 힌트를 연다. 멀티에서는 힌트와 첫 정답·스킵의 결과를 함께 공유한다. 정답 공개 후에는 풀이·빠른 접근·다섯 선지의 판정 근거를 확인하고 방장이 다음 문제로 넘긴다. 상식퀴즈는 단답형과 자동 힌트 규칙을 그대로 사용한다.

## 검증

수리 문제의 답은 문제별로 별도 산식·정수 탐색·조합 계산으로 재계산한다. 배치·일정·부서 배정·참거짓 문제는 가능한 배치를 전수 열거하여 정답 선지가 하나인지 확인한다. 명제 문제는 유한 모델의 전제 만족 여부와 결론의 반례를 검사한다. 언어 문제는 지문 내 근거와 선지의 범위 확대·인과 단정·지시어 연결을 검토하고 오답 근거를 작성했다. 기존 게임과 섞이지 않음, 정답 유출 방지, 1회 제출, 스킵, 힌트, 해설 대기, 방장만 다음 문제로 넘길 수 있음도 테스트한다.

OfficeChat Windows 앱

1. ZIP을 풀고 OfficeChat.exe를 실행합니다. 별도 설치가 없습니다.
2. 이름을 입력하고 새 대화를 만든 뒤 링크나 방 코드를 공유합니다.
3. 다른 참여자는 앱에 방 코드를 입력하거나 웹 링크로 들어옵니다.
4. 방장은 상단 메뉴에서 시작하고, 엔터로 단어를 전송합니다.

지원 환경: Windows 10/11 64비트, Microsoft Edge, 인터넷 연결.
이 실행 파일은 Edge의 독립 앱 창을 열고 관리하는 Windows 프로그램입니다.
주소창과 탭은 표시하지 않으며, 기존 Edge 사용자 프로필과 별개 프로필을 사용합니다.
게임과 단어 검사는 인터넷 서버에서 처리합니다.

창을 최소화하면 트레이로 숨깁니다.
창을 닫아도 트레이 프로그램은 남습니다. 트레이 아이콘으로 다시 열 수 있습니다.
트레이 아이콘을 오른쪽 클릭하면 대화 열기 / 항상 위 / 창 숨기기 / 종료가 있습니다.
완전히 종료하려면 트레이 메뉴의 종료를 선택합니다.
Esc는 게임 화면을 빈 대화창으로 바꾸고, 다시 누르면 돌아옵니다.
이름과 마지막 방은 앱을 다시 실행하면 자동 복원합니다.

단어: 사전 명사 32,589개 / 확장 단어 211,277개.
확장 단어에는 인명, 지명, 작품명 및 게임 관련 명칭이 포함됩니다.
방장은 대기 중 단어 범위를 변경할 수 있습니다. 끄투의 전체 사전과 동일한 목록은 아닙니다.
미등록 단어는 방장이 확인해 추가할 수 있습니다.

웹 화면의 방 복원, 단어 범위 변경, 기본 게임 규칙과 단어 목록은 확인했습니다.
이 빌드는 Windows PC에서 직접 실행하지 못했으며, 실제 트레이·창 제어 동작은 실행 확인이 필요합니다.
코드 서명은 하지 않았습니다.
